# Flow support removed

WatermelonDB's JavaScript source is TypeScript. Flow types, `.flowconfig`, and `flow-bin` are no longer shipped.

Use [TypeScript](https://www.typescriptlang.org/) instead. See the [TypeScript example](https://github.com/Nozbe/WatermelonDB/tree/master/examples/typescript) for model, schema, and query typing.
