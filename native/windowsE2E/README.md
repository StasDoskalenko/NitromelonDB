# WatermelonTester Windows E2E (retired)

This RNW 0.71 WinAppDriver runner targeted UWP `WatermelonTester`. That native stack is gone.

Windows CI now builds [`examples/NotesApp_windows`](../../examples/NotesApp_windows) on `windows-2025` and runs the Cavy SQLite suite with `@react-native-windows/automation` (WinAppDriver is already on that image).
